# Asteroid Blaster

**Fly a ship, shoot asteroids, collect power-ups and beat the boss.**
Open `index.html` in a browser.

## Controls
- **Arrow keys or WASD:** move
- **Space:** shoot
- Click **LAUNCH** to start and **RETRY** after losing

## Features
Power-ups to collect and a boss fight.

## How it works
Canvas game loop. Each frame it moves the ship, bullets and asteroids, checks collisions (hit tests between objects), updates the score, and redraws.

## What I learned
Collision detection and managing many moving objects at once.
